# SVO GAME 22-26 — версия 0.3.1 (этап 2, уточнение: карта мест сценариев)

Стратегическая 2D-игра с видом сверху на Godot 4 (GDScript) для Android.
Версия 0.3.1 переработала карту 0.3.0 вокруг мест сценариев; 0.3.0 добавляла интерактивную карту Украины (см. раздел «Глобальная карта»). Версия 0.2.0 — рабочий фундамент с отбалансированным боем: меню, глобальная карта, тестовые бои, камера,
выделение, круговое меню, ИИ, пауза/ускорение, условия победы и сохранение.
Графика временная (условные знаки), боевые механики — игровые и условные.

## Требования

- Godot **4.2 или новее** (стандартная сборка, не .NET). Рендерер: Compatibility (OpenGL) — лучший вариант для Android.
- Для сборки APK: Android SDK, JDK 17, шаблоны экспорта Godot (Editor → Manage Export Templates).

## Запуск на компьютере

1. Откройте Godot, нажмите **Import**, выберите `project.godot`.
2. Нажмите **F5**. Откроется главное меню.
3. «Тестовая карта (быстрый старт)» запускает бой сразу; «Глобальная карта и сценарии» — полный путь: территория → сценарий → сторона.

## Запуск на Android

1. Editor → Editor Settings → Export → Android: укажите пути к Android SDK и JDK.
2. Project → Install Android Build Template (если требуется Gradle-сборка) или используйте экспорт без неё.
3. Project → Export → Add… → Android. Создайте debug-keystore (или используйте автоматический debug-ключ).
4. На вкладке **Resources** в поле **Filters to export non-resource files/folders** впишите: `data/*` — иначе JSON-данные не попадут в APK.
5. Подключите устройство (режим отладки USB) и нажмите кнопку «Remote Debug» (значок Android) либо Export Project → APK.

Ориентация экрана — горизонтальная (по датчику).

## Автоматическая сборка APK (GitHub Actions)

Godot на телефон ставить не нужно: debug-APK собирается на серверах GitHub.

1. Загрузите проект в репозиторий GitHub так, чтобы папка `.github/` лежала в корне репозитория (сам проект может быть в корне или в одной вложенной папке — `project.godot` ищется автоматически).
2. Откройте вкладку **Actions** → **Android APK (debug)** → **Run workflow** (в браузере телефона может понадобиться режим «Версия для ПК»). Сборка также запускается сама при каждом push в `main`/`master`.
3. Дождитесь зелёной галочки (обычно 5–10 минут), откройте запуск и скачайте artifact **svo-game-debug-apk-…** — это zip с `svo_game_debug.apk`.
4. Распакуйте zip на телефоне (приложение «Файлы») и установите APK. Android попросит разрешить установку из неизвестных источников.

Что делает workflow (`.github/workflows/android-apk.yml`): ставит Godot 4.2.2 и шаблоны экспорта (с проверкой SHA-512), JDK 17 и Android SDK (Build-Tools 34.0.0, Platform 34), создаёт debug-keystore, импортирует проект, запускает сцены в headless-режиме для поиска ошибок GDScript, экспортирует пресет **Android debug** из `export_presets.cfg`, проверяет подпись и содержимое APK и сохраняет его как artifact (14 дней). Логи сборки сохраняются отдельным artifact. Любая ошибка скриптов, экспорта или подписи останавливает сборку, фиктивный APK не создаётся.

Ограничения: это debug-подпись, её нельзя использовать для публикации в магазине (нужен отдельный release-ключ). Ключ создаётся заново при каждой сборке, поэтому обновить уже установленную версию поверх старой Android может не позволить — тогда сначала удалите старую.

## Боевая модель (этап 1)

- **Рельеф влияет на правила**: лес замедляет технику и даёт укрытие, город даёт сильное укрытие, вода сильно замедляет,
  дорога ускоряет технику. Значения — в `data/balance.json`, карта рисуется и считается из одних и тех же данных сценария.
- **Урон зависит от класса цели**: у каждого типа есть `dmg_vs_infantry` и `dmg_vs_vehicle` (`data/equipment/unit_types.json`),
  урон падает с дальностью (`range_falloff`), цели выбираются с фокусировкой огня (ближние, раненые, уязвимые).
- **Юниты не слипаются** (мягкое разведение), уничтоженные оставляют обломки, на экране результата видны потери.
- **ИИ**: ближайшие цели первыми, раненые отступают только если рядом враг сильнее и больше не возвращаются сами,
  осторожный ИИ (агрессивность < 0.5) держит зону своей точки.

### Стенд баланса

Прогон боёв ИИ против ИИ без графики (быстро, секунды):

```
godot --headless --path . res://tools/balance_sim.tscn -- scenario=all runs=100
```

Параметры: `scenario=<id|all>`, `runs=<число>`, `step=<сек>`, `strict=1` (код 1, если бой не завершился).
Выводит доли побед, причины завершения и длительность. Результаты после настройки этапа 1 (200 боёв на сценарий):

| Сценарий | Сторона А | Сторона Б | Средняя длительность |
|---|---|---|---|
| test_01 (симметричная карта) | 52% | 48% | около 3,5 мин из 10 |
| test_02 (оборона узла) | 41% | 59% (в основном по таймеру) | около 6,5 мин из 8 |

Шаг в CI выполняет короткий прогон (6 боёв) и останавливает сборку при ошибках скриптов.

## Управление

| Действие | Касание | Мышь/клавиатура |
|---|---|---|
| Выбрать подразделение | Касание | Левая кнопка |
| Круговое меню команд | Касание подразделения | Левая кнопка |
| Выбрать несколько | Кнопка «Выбор: один» → «Выбор: рамка», затем касания или рамка | То же, либо Shift + рамка |
| Команды для группы | Кнопка «Команды» или касание выбранного | То же |
| Двигать камеру | Перетаскивание по пустому месту | Правая/средняя кнопка, WASD, стрелки |
| Масштаб | Щипок двумя пальцами | Колесо мыши |
| Снять выделение | Касание пустого места | Левая кнопка |
| Меню паузы | Кнопка «Меню» / системная «Назад» | — |

Порядок команды: **подразделения → команда → точка назначения**.
Пехота и смешанные группы получают круговое меню, группы из одной техники — отдельную панель действий справа.

Команды: Идти, Бег (быстрее, без стрельбы), Атака (наступление с остановкой для боя),
Ждать (удержание позиции), Посадка / Высадка (пехота ↔ транспортёр), Окопаться (техника).

Время: «Пауза/Пуск», x1 — реальное время, x2, x4, x8 — ускорение. Приказы можно отдавать на паузе.

## Глобальная карта (этап 2, версия 0.3.1)

**Главное — места сценариев, а не области.** Области остались только географической основой (границы, слабые подписи).

- **Места сценариев** (`data/global_map/places.json`): 47 мест и 48 событий из перечня автора проекта (2014–2026) плюс 2 вымышленных
  тестовых. Маркер — ромб; цвет зависит от года (2014 / 2022 / 2023 / 2024+ / тест), тусклый маркер — даты не сверены.
  Касание маркера открывает карточку: даты, статус проверки, описание, ссылки на источники. Фильтр по годам и список мест — в панели.
- **Что реально играбельно.** Боевые сценарии есть только у двух вымышленных тестов. Для исторических мест создана карточка,
  но боевая карта и силы сторон не созданы (этап 7) — кнопка «Играть» там не показывается, это написано в карточке.
- **Проверка по источникам.** Полный список со статусами — `docs/PLACES.md`. Подтверждены по источникам: Славянск и Краматорск (2014),
  Луганская погранбаза (2014), коса Тендра (2024), рейды 2023 года, рейд в Белгородскую/Курскую области (март 2024). Частично:
  Карачун, аэропорт Луганска. Остальные события помечены «требует проверки»: годы ориентировочные, описаний нет.
  Не определены места: «32-й блокпост», «Новопавловское направление», «Ольговский лес» (в списке без координат), «Южный котёл» — название не подтверждено.
- **Контроль территорий** на карте не показывается: все области нейтральны, итоги вымышленных боёв области не перекрашивают.
  Контроль появится только в исторических сценариях с датой и источником (этап 7).
- **Контур**: границы областей получены из схемы, предоставленной автором проекта (`tools/extract_regions.py`, привязка по 25 городам,
  средняя невязка около 0,06°, максимум 0,21°). Береговая линия схемы грубая: береговые города слегка сдвинуты на сушу.
  Реки, рельеф (Карпаты, Крымские горы, Полесье) и «коридоры» — ориентирные точки; текстура местности процедурная.
- **Управление**: перетаскивание с инерцией, щипок, колесо мыши, кнопки «+», «-», «Вся», кнопка «Панель». Положение камеры и выбранное место
  сохраняются при переходе в бой и обратно.
- Генератор данных: `python3 tools/gen_ukraine.py --preview preview.png` (нужны numpy, scipy, opencv, matplotlib; только разработчику).

Графика боевых карт (как на присланных скриншотах: текстуры полей, постройки, техника сверху) — этап 5, а не глобальная карта.

## Как расширять

- **Новый тип подразделения или техники**: добавьте запись в `data/equipment/unit_types.json` (характеристики, `symbol`, `shape`, `capacity`, `actions`). Код менять не нужно.
- **Новый сценарий**: создайте `data/scenarios/<id>.json` по образцу `test_01.json`, добавьте путь в `data/manifest.json` и id сценария в поле `scenarios` нужной территории в `territories.json`.
- **Новая сторона**: добавьте запись в `data/factions/factions.json`.
- **Новая команда**: запись в `command_defs.gd`, обработка в `command_executor.gd`, id в `actions` типов.
- **Исторические названия, даты и обстановка** хранятся только в JSON (`name`, `kind`: `historical`/`fictional`, `date_label`, `description`). Текущие названия — условные заглушки.

## Правила матча (из данных сценария)

Для каждой стороны: `win_conditions` — `eliminate_enemy` (уничтожить противника), `control_all_points` (удерживать все точки);
`timeout_result` — исход при истечении `time_limit` (`victory`/`defeat`). Итог сохраняется в `user://svo_save.json`
и меняет владельца территории сценария на глобальной карте (победа — территория игрока, поражение — противника, ничья — «спорная»).

## Известные ограничения (на версию 0.3.0)

- Глобальная карта (этап 2) проверена только статически: данные — скриптом (JSON, простота полигонов), код GDScript проверит CI при сборке. В Godot и на телефоне карта не запускалась: жесты, скорость, вид процедурных текстур нужно проверить на устройстве.

## Известные ограничения версии 0.1

- Проект проверен в Godot 4.2.2 в headless-режиме (импорт, запуск всех трёх сцен, симуляция матча, экспорт APK), но на реальном телефоне ещё не тестировался: сенсорное управление и производительность нужно проверить на устройстве.
- Рельеф влияет на скорость и укрытие, но поиска пути и непроходимых препятствий нет.
- Нет тумана войны: игрок видит всех; `vision` используется ИИ.
- ИИ простой (характеры сторон — этап 9). Инфантерия плохо уничтожает технику: бой с бронёй затягивается (задумано, значения в balance.json).
- Ощутимый разброс баланса остаётся: точные цифры нужно подтверждать на реальных играх, стенд — это ИИ против ИИ.
- Звука и настоящей графики нет; поддержка нескольких игроков и больше двух сторон не реализованы.
- Прогресс глобальной карты сбрасывается кнопкой «Сбросить прогресс» в главном меню.
